# Signals and Systems Coursework Collection

This repository collects several MATLAB assignments from the Signals and Systems course.

## Included assignments

- `CHW2` — CTFT properties, audio-domain experiments, and amplitude modulation
- `CHW3` — DFT implementation, spectral leakage, convolution, DTMF, and 2D image filtering
- `CHW4` — Laplace transform, control stability, Z-transform, and ECG denoising
- `CHW5` — sampling theory, aliasing, reconstruction, and anti-aliasing filtering

## Recommendation for portfolio use

If you want to keep only the strongest material, prioritize:

1. `CHW3`
2. `CHW4`
3. `CHW5`
4. `CHW2`

`CHW2` is still useful, but it is the most coursework-like and the least standalone among the four.
